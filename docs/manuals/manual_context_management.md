# คู่มือการใช้งาน: การจัดการบริบทข้อมูล (Context Management)

ฟีเจอร์ **Multi-Context Data Support** ช่วยให้ AI สามารถเลือก "บริบท" (Context) ของข้อมูลที่ถูกต้องตามคำถามของผู้ใช้ เช่น เมื่อถามเรื่อง "ยอดขาย" AI จะไปดูตารางรายได้ หรือเมื่อถามเรื่อง "ค่าใช้จ่าย" AI จะไปดูตารางค่าใช้จ่าย โดยอัตโนมัติ

## 1. การเข้าใช้งาน
1. เข้าสู่ระบบ Admin UI (`http://localhost:5173/login`)
2. ที่แถบเมนูด้านซ้าย เลือก **"Data Contexts"** (หรือบริบทข้อมูล)

## 2. หน้าจอแสดงผล (Context List)
หน้าจอจะแสดงรายการบริบทที่มีอยู่ในระบบ ประกอบด้วย:
- **ID**: รหัสอ้างอิง
- **Internal Name**: ชื่อภายในระบบ (ห้ามซ้ำ) เช่น `revenue`, `expense`
- **Display Name**: ชื่อที่แสดงให้เห็น เช่น `รายได้`, `ค่าใช้จ่าย`
- **Main View**: ชื่อตารางหรือ View หลักในฐานข้อมูลที่เกี่ยวข้อง
- **Priority**: ลำดับความสำคัญในการตรวจสอบ (ตัวเลขมาก = ตรวจสอบก่อน)

## 3. การเพิ่มบริบทใหม่ (Add Context)
คลิกปุ่ม **"Add Context"** และกรอกข้อมูลดังนี้:

| ฟิลด์ | คำอธิบาย | ตัวอย่าง |
|-------|----------|----------|
| **Internal Name** | ชื่อภาษาอังกฤษตัวเล็ก ห้ามเว้นวรรค | `marketing` |
| **Display Name** | ชื่อที่สื่อความหมาย (ไทย/อังกฤษ) | `การตลาด` |
| **Description** | คำอธิบายเพิ่มเติม | `ข้อมูลแคมเปญและการเข้าถึง` |
| **Main View** | **สำคัญมาก:** ชื่อตาราง/View จริงใน DB | `v_marketing_stats` |
| **Routing Priority** | ความสำคัญ (0-100) | `10` |
| **Routing Keywords** | **สำคัญมาก:** คำคีย์เวิร์ดสำหรับจับคู่คำถาม | `["marketing", "campaign", "ads", "โฆษณา"]` |

> **ข้อควรระวังเรื่อง Keywords:** ต้องใส่ในรูปแบบ **JSON Array** (วงเล็บก้ามปู `[]` และเครื่องหมายคำพูดคู่ `""`) 
> * ✅ ถูก: `["sales", "ยอดขาย"]`
> * ❌ ผิด: `sales, ยอดขาย` (ไม่มีวงเล็บ)

## 4. การแก้ไข (Edit)
1. คลิกที่ปุ่ม **"Edit"** (ไอคอนดินสอ) ท้ายแถวที่ต้องการแก้ไข
2. ปรับปรุงข้อมูล เช่น เพิ่ม Keywords ใหม่ๆ เข้าไปเพื่อให้ AI ฉลาดขึ้น
3. กด **Save** เพื่อบันทึก

## 5. การทำงาน (How it works)
เมื่อผู้ใช้ถามคำถามใน Chat:
1. ระบบ `ContextRouter` จะตรวจสอบคำถามของผู้ใช้เทียบกับ **Keywords** ของทุกบริบท
2. หากพบคำที่ตรงกัน (เช่น "ขอดู**ยอดขาย**หน่อย") ระบบจะเลือกบริบทที่มีคะแนนสูงสุด (ในที่นี้คือ `revenue`)
3. AI จะถูกสั่งให้สร้าง SQL จากตารางที่ระบุใน **Main View** ของบริบทนั้นๆ (`revenue_search`) เท่านั้น ทำให้ลดความสับสนและเพิ่มความแม่นยำ

## 6. ปุ่ม Sync Metadata
- ใช้เมื่อมีการเปลี่ยนแปลงโครงสร้างฐานข้อมูล (เช่น เพิ่ม View ใหม่) และต้องการให้ระบบโหลดรายการ Context ใหม่จากฐานข้อมูล (กรณีที่มีการแก้ไขหลังบ้านโดยตรง)
